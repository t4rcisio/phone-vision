# Changelog

## 1.3.0 — 2026-11-12

First public release of Phone Vision.

- English application interface, accessibility labels, documentation, and code comments.
- Explicit Moondream visual queries: questions, descriptions, detection, pointing/counting, segmentation, and text reading.
- Independent ARCore camera with environmental anchors and capture-time depth reprojection.
- Offline YOLO instance segmentation, multiple-category filters, temporal IDs, and fast optical-flow tracking.
- Source-frame replay to compensate for movement during model inference.
- Persistent private history, aligned snapshots, gallery export, and encrypted runtime API credentials.
- Camera-first glass interface, corrected text contrast, adaptive icon, and percent-safe overlay labels.
- Illustrated architecture, supplied screenshots, animated preview, and a full recorded demonstration.
- Public-data regression fixtures, secret scanning, publication hygiene checks, and pinned read-only CI.
- Signed, non-debuggable ARM64 release APK. Signing keys and local development data are excluded from source control.
